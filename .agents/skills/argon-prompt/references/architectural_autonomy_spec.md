# Architectural Autonomy within Hard Invariants: Prompt Engineering Specification

## 1. Executive Summary & Routing Heuristic Rationale

Modern LLM routers in frontier evaluation platforms (such as Arena.ai LMSYS Max Router) utilize dynamic **Task Complexity Scoring (TCS)** to route prompts to either **Tier 1 Frontier Models** (Claude Fable 5.2 Max, Claude Opus 5.5 Max, Gemini 4 Carbon, Gemini 4 Argon High) or **Tier 2/3 Routine Models** (Astra Medium, Terra, Flash).

### The Micromanagement Down-Routing Failure Mode
Historical prompt templates handcuffed models with rigid, step-by-step procedural pseudo-code ("Step 1: Open file X. Step 2: Add import Y. Step 3: Write function foo(a, b)..."). 
This caused immediate down-routing because:
1. **Collapses Reasoning Tree Depth to $O(1)$**: The prompt author pre-solved the architecture and logic; the task degenerated into mechanical stenography.
2. **Win-Rate Parity on Procedural Code**: Routine models achieve ~96–98% parity with frontier models on simple transcription at 1/10th the inference cost.
3. **Compute Over-Allocation Penalty ($P_{\text{script}}$)**: Allocating 64,000 extended thinking tokens (CoT) to transcribe a pre-solved script is penalized as wasteful by the router.

### The Paradigm Shift: Architectural Autonomy within Hard Invariants
To maximize the probability of routing to Tier 1 Frontier models, prompts must replace procedural micromanagement with **Architectural Autonomy within Hard Invariants**:
- Maximize **Cross-Boundary Coupling ($S_{\text{cross}}$)**: Span 2–3 coupled architectural tiers simultaneously.
- Maximize **Invariant Density ($S_{\text{invariant}}$)**: Define declarative post-conditions, security bounds, and mathematical correctness guarantees.
- Preserve **Semantic Signal-to-Noise Ratio**: Inject surgical Type Spines (< 3,500 tokens) extracted via AST tools rather than dumping raw code.
- Enforce **Deterministic Falsifiability ($S_{\text{verif}}$)**: Concrete container verification commands (`tsc --noEmit`, `npm test`, pytest).
- Grant **Explicit Architectural Freedom**: Delegate full ownership of data structures, concurrency primitives, and state machines to the model, forcing the router to allocate deep CoT search space.

## 3. Autonomous Turn-Slicing Protocol (< 3,500 Token Budget)

When an assignment spans >= 3 cross-boundary files or requires > 300 lines of implementation, Antigravity slices the task into **Autonomous Architectural Milestones** rather than procedural step lists:

- **Turn 1: Foundation, Domain Logic & Worker Concurrency**:
  - The model has full architectural autonomy over the database schema, domain algorithms, and backend worker lifecycles.
  - Invariant Gate: `(cd web && npx tsc --noEmit)` and `(cd agent-worker && .venv/bin/python -m unittest discover -s tests)`.
- **Turn 2: Reactive UI, Streaming & Telemetry**:
  - The model has full architectural autonomy over client state machines, real-time visualizer loops, and telemetry integration.
  - Invariant Gate: `npm test` and `POST http://localhost:4000/api/webhook/arena`.

## 5. Anti-Pattern Checklist: Purging Handcuffs & Down-Routing Triggers

When auditing or generating prompts, ensure none of the following down-routing triggers are present:

| Anti-Pattern (Down-Routing Trigger) | Why It Causes Down-Routing | Required Replacement Pattern |
|---|---|---|
| **Step-by-step procedural pseudo-code** ("Step 1 do this, Step 2 do that") | Pre-solves the logic, collapsing reasoning tree depth ($S_{\text{depth}}$) to $O(1)$ and triggering the Micromanagement Penalty ($P_{\text{script}}$). | **High-Complexity Multi-Tier Problem Statement** + **Explicit Architectural Freedom Grant**. |
| **Steerability Hype** ("Act as an elite 10x architect", "Use maximum genius") | Triggers Arena's Steerability Penalty ($P_{\text{steer}}$) and results in session downgrades to cheap models. | **Objective, high-density technical specifications** describing real invariants and domain complexities. |
| **Raw Repository Code Dumps** (>10,000 tokens) | Triggers Context Bloat Penalty ($P_{\text{bloat}}$), DOM freezes in web client, and dilutes attention heads. | **Surgical Type Spine (< 3,500 tokens)** extracted via AST tools with function bodies stripped to `...`. |
| **Vague or Missing Verification** ("Please test your code") | Fails to signal deterministic falsifiability ($S_{\text{verif}}$) to the router. | **Concrete container shell commands** (`(cd web && npx tsc --noEmit)`, `npm test`, `pytest`). |
| **Single-File Trivial Helpers** | Low cross-boundary complexity ($S_{\text{cross}}$) signals a task suitable for routine utility models. | **Multi-tier problem formulation** coupling database, transport, and client layers simultaneously. |
